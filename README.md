# NUR — Эхо Тишины

Рисованное 2D сюжетное приключение для телефонов (Android, браузер на iPhone) на Godot 4 (рендерер GL Compatibility). Вид сверху под углом, стиль — сказочная книжная иллюстрация.

> Каждую зиму с Белого Пика спускается Тишина. Сначала она забирает имена. Потом — лица. Потом — людей.

Сюжет, персонажи и режиссура описаны в [docs/story.md](docs/story.md).

## Что уже есть (глава I, первая сцена)
- Вступление: титры на чёрном, титул поверх деревни, карточка главы.
- Деревня у Подножия — нарисованная сцена, по которой ходит Нур (три вида, процедурная походка, тёплый свет, следы на снегу).
- Разговоры с портретами эмоций Нур: бабушка Зара, Путник, мать, забывшая лицо дочери.
- Сцена у колодца: «Тётя… а вы кто?»
- Тишина: туман, гаснущие фонари, Безликий поднимается по лестнице.
- Механика «вернуть имя»: найти вещь (лошадка «Арсен») → осколок памяти → у Безликого появляется лицо, он уходит в свет.
- Весь звук (ветер, колокол) синтезируется кодом.

## Играть на iPhone (браузер)
Каждый push собирает веб-версию и публикует её в ветку `gh-pages`.
Ссылка: **https://said240705.github.io/nur-game/** (нужно один раз включить GitHub Pages:
Settings → Pages → Source: *Deploy from a branch* → `gh-pages` / `root`).
Телефон держать горизонтально.

## Как получить APK
Каждый push собирает отладочный APK в GitHub Actions (workflow **Build game**).
Открой вкладку **Actions** → последний запуск → в блоке **Artifacts** скачай `nur-debug-apk`,
распакуй zip и установи `nur-debug.apk` на телефон (разреши установку из неизвестных источников).

## Запуск на компьютере
1. Скачай [Godot 4.7](https://godotengine.org/download).
2. Открой папку проекта в Godot и нажми ▶. Управление: мышь (зажать и тянуть) или WASD.

## Структура
| Путь | Что там |
|---|---|
| `scripts/main.gd` | Режиссёр: вступление, титул, паузы, кат-сцены, финал |
| `scripts/village/` | Сцена деревни: где можно ходить, жители, фонари, туман, камера |
| `scripts/actors/` | Нур, Безликий, потерянная вещь, следы |
| `scripts/ui/` | Джойстик и кнопка «Говорить», окно диалога с портретами, «кино» (затемнения, полосы, титры) |
| `assets/art/` | Арт из ChatGPT: концепты, вырезанные виды и эмоции Нур, деревня |
| `scripts/audio/sfx.gd` | Процедурный звук |
| `scripts/texts.gd` | Все тексты игры |
| `shaders/` | Туман Тишины |
| `scripts/dev/autoshot.gd` | Инструмент разработчика: автопрогон и скриншоты (`godot -- --mode=game --shots=DIR`) |
