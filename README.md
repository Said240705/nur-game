# Сияние

Простая и залипательная головоломка из сияющих блоков. Перетаскивай фигуры на поле 8×8, собирай полные ряды и столбцы — они взрываются искрами. Чем больше линий за раз, тем больше очков; если снова собираешь линию в течение трёх ходов, растёт комбо-множитель. Игра заканчивается, когда ни одна из трёх фигур больше не помещается.

Godot 4 (GL Compatibility), Android и браузер (iPhone). Вся графика и все звуки сделаны кодом, без картинок и звуковых файлов; фоновая музыка синтезирована скриптом `tools/music/make_music.py`.

## Играть на iPhone (браузер)
**https://said240705.github.io/nur-game/** — обновляется после каждого push (ветка `gh-pages`).

## APK для Android
Вкладка **Actions** → последний запуск **Build game** → артефакт `nur-debug-apk`.

## Структура
| Путь | Что там |
|---|---|
| `scripts/main.gd` | Экраны: заставка, конец партии, кнопки звука и музыки |
| `scripts/game/game.gd` | Партия: перетаскивание, очки, комбо, конец игры |
| `scripts/game/board.gd` | Правила поля 8×8 |
| `scripts/game/shapes.gd` | Все фигуры и как часто они выпадают |
| `scripts/game/dealer.gd` | Раздача трёх фигур (честная и иногда щедрая) |
| `scripts/game/board_view.gd` | Отрисовка поля, тени фигуры, взрывов линий |
| `scripts/game/blocks.gd` | Глянцевые блоки-самоцветы, созданные кодом |
| `scripts/game/background.gd`, `fx.gd` | Ночное небо, искры, конфетти |
| `scripts/audio/sfx.gd` | Синтезированные звуки и фоновая музыка |
| `scripts/save.gd` | Рекорд, настройки и незаконченная партия |
| `scripts/dev/` | Тест правил и автоигра со скриншотами |

Проверки: `godot --headless --script res://scripts/dev/test_rules.gd`, скриншоты: `godot -- --mode=play --shots=DIR`.
