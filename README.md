# Была в сети

Детектив внутри чужого телефона. Вертикальный экран, интерфейс настоящего смартфона, нуарный пролог с закадровым голосом. Godot 4 (GL Compatibility), Android и браузер (iPhone).

Сюжет и повороты — [docs/story.md](docs/story.md).

## Что уже есть (пролог)
- Кадр из будущего, «72 часа назад», титул над ночным городом, закадровый голос Льва.
- Телефон Льва как обучение: экран блокировки, сообщения, заметки, новости, голосовые, фото.
- Звонок в дверь, посылка, записка, телефон Миры с кодом-загадкой и переключение между телефонами.
- Весь звук (дождь, вибрация, звонок в дверь, клавиши) синтезируется кодом.

## Играть на iPhone (браузер)
**https://said240705.github.io/nur-game/** — обновляется после каждого push (ветка `gh-pages`).

## APK для Android
Вкладка **Actions** → последний запуск **Build game** → артефакт `nur-debug-apk`.

## Структура
| Путь | Что там |
|---|---|
| `scripts/main.gd` | Режиссёр пролога |
| `scripts/phone/phone.gd` | «Операционная система» телефона: блокировка, рабочий стол, приложения |
| `scripts/story/` | Содержимое телефонов Льва и Миры |
| `scripts/ui/` | Кинокадры, «кино» (затемнения, титры), цель, мысли Льва, записка |
| `scripts/texts.gd` | Все тексты пролога |
| `shaders/grade.gdshader` | Единая цветокоррекция для всех иллюстраций |
| `assets/art/` | Арт из ChatGPT |
| `scripts/dev/autoshot.gd` | Автопрогон и скриншоты (`godot -- --mode=lev --shots=DIR`) |
