# Золотая жила

Шахта-симулятор: тапай шахтёров, лифт и склад, зарабатывай монеты, улучшай всё и нанимай управляющих — тогда шахта работает сама, даже когда игра закрыта. Открывай новые шахты всё глубже: уголь, медь, железо, серебро, золото, рубины, изумруды, сапфиры, аметисты и алмазы.

Godot 4 (GL Compatibility), Android и браузер (iPhone). Вся графика и звуки сделаны кодом; фоновая музыка синтезирована скриптом `tools/music/make_music.py`.

## Как устроено
Руда идёт в три шага: шахтёр копает и складывает в ящик → лифт собирает ящики и поднимает наверх → рабочий относит руду на склад и продаёт. Самый медленный шаг ограничивает доход, поэтому важно улучшать всё по очереди. Каждые 25 уровней станция удваивает добычу. Кнопка «×2» удваивает доход на 2 минуты (перезарядка 5 минут).

## APK для Android
Вкладка **Actions** → последний запуск **Build game** → артефакт `nur-debug-apk`.

## Структура
| Путь | Что там |
|---|---|
| `scripts/main.gd` | Верхняя панель, подсказки, сохранение, «пока тебя не было» |
| `scripts/game/economy.gd` | Руды, цены, формулы, короткие числа (1.2K, 3.4M) |
| `scripts/game/mine.gd` | Модель шахты: шахтёры, лифт, склад, управляющие, офлайн-доход |
| `scripts/game/world.gd` | Рисунок шахты в разрезе, прокрутка и тапы |
| `scripts/game/sheet.gd` | Панель улучшений |
| `scripts/audio/sfx.gd` | Синтезированные звуки и музыка |
| `scripts/dev/` | Автоигра со скриншотами и симуляция темпа игры |

Проверки: `godot --headless --script res://scripts/dev/sim_pacing.gd` (когда открываются шахты), скриншоты: `godot -- --mode=start --shots=DIR`.
