# NUR — Эхо Тишины

Кинематографичная 3D-игра в стиле анимационного кино для телефонов (Android, браузер на iPhone) на Godot 4 (рендерер GL Compatibility).

> Каждую зиму с Белого Пика спускается Тишина. Сначала она забирает имена. Потом — лица. Потом — людей.

Сюжет, персонажи и режиссура описаны в [docs/story.md](docs/story.md).

## Что уже есть (пролог)
- Вступление: титры на чёрном, пролёт камеры над ночной деревней к Белому Пику, реплика Эли, титул.
- 3D-долина: звёздное небо с луной, снежное поле, деревня с тёплыми окнами, лес, горы на горизонте, снегопад.
- Нур (временная модель) со своим тёплым светом; свет сам бьёт волнами, искры кружат вокруг.
- Безликие — полупрозрачные фигуры в вуалях без лиц, растворяются в свете.
- Осколки памяти → прокачка света (7 улучшений) и 5 воспоминаний-кат-сцен.
- Финал пролога; если свет гаснет — Нур падает и всё начинается заново.
- Весь звук (ветер, колокол, пульс) синтезируется кодом.

## Играть на iPhone (браузер)
Каждый push собирает веб-версию и публикует её в ветку `gh-pages`.
Ссылка: **https://said240705.github.io/nur-game/** (нужно один раз включить GitHub Pages:
Settings → Pages → Source: *Deploy from a branch* → `gh-pages` / `root`).
Телефон держать горизонтально.

## Как получить APK
Каждый push собирает отладочный APK в GitHub Actions (workflow **Build game**).
Открой вкладку **Actions** → последний запуск → в блоке **Artifacts** скачай `nur-debug-apk`,
распакуй zip и установи `nur-debug.apk` на телефон (разреши установку из неизвестных источников).

## Запуск на компьютере
1. Скачай [Godot 4.7](https://godotengine.org/download).
2. Открой папку проекта в Godot и нажми ▶. Управление: мышь (зажать и тянуть) или WASD.

## Структура
| Путь | Что там |
|---|---|
| `scripts/main.gd` | Режиссёр: вступление, титул, паузы, кат-сцены, финал |
| `scripts/world/` | 3D-долина: небо, снег, деревня, лес, горы, камера и её пролёты |
| `scripts/game/` | Игра: Нур, Безликие, осколки памяти, следы |
| `scripts/ui/` | HUD с джойстиком, «кино» (затемнения, полосы, титры), выбор улучшений |
| `assets/` | 3D-модели KayKit (CC0): временная Нур, дома, деревья, камни |
| `scripts/audio/sfx.gd` | Процедурный звук |
| `scripts/texts.gd` | Все тексты игры |
| `shaders/` | Небо, снег, снежные шапки на моделях, далёкие горы, Безликие |
| `scripts/dev/autoshot.gd` | Инструмент разработчика: автопрогон и скриншоты (`godot -- --mode=game --shots=DIR`) |
